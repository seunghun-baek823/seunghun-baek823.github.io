# 백승훈 개인 프로필 사이트

블랙 미니멀 디자인의 반응형 정적 웹사이트입니다. 한국어와 영어를 전환할 수 있습니다.

## 구성

- 소개: 백승훈의 경력과 사업 방향
- 사업과 역할: 알파리졸브 대표, 대성네트웍 부사장
- 관심 분야: AI 기반 현장업무 자동화, MES, FEMS
- 연결: 알파리졸브 홈페이지, 공식 Instagram

외부 패키지나 빌드가 필요하지 않습니다. `index.html`에 디자인과 언어 전환 코드가 포함되어 있어 파일을 직접 열어 확인할 수 있습니다. 언어 선택만 브라우저에 저장하며, 분석·추적·문의 제출 기능은 없습니다.

## GitHub Pages 게시

1. GitHub 계정에서 `<사용자명>.github.io` 이름의 저장소를 만듭니다. 무료 개인 계정은 공개 저장소를 사용합니다. 이미 같은 이름의 저장소가 있다면 기존 파일을 확인한 뒤 반영합니다.
2. 이 폴더의 `index.html`과 `.nojekyll`을 저장소의 `main` 브랜치 최상위에 올립니다.
3. 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. 브랜치는 **main**, 폴더는 **/(root)**로 지정하고 저장합니다.
5. 게시 완료 후 `https://<사용자명>.github.io/`에서 확인합니다. 반영에 수 분이 걸릴 수 있습니다.

일반 저장소 이름도 사용할 수 있습니다. 이 경우 기본 주소는 `https://<사용자명>.github.io/<저장소명>/`입니다.

공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## 내용 수정

`index.html`의 `data-ko`는 한국어, `data-en`은 영어 문구입니다. 두 속성과 기본 표시 문구를 함께 수정합니다. 이름의 영문 표기는 **SEUNGHUN BAEK**입니다.

본 사이트의 소개 문구는 제공된 사업·직책 정보를 바탕으로 작성한 초안입니다. 특정 고객 실적, 매출, 수상, 성과 수치는 포함하지 않았습니다. 연락처는 회사 공식 채널로 연결합니다.
